# RegShield

A compliance-focused RAG platform that retrieves regulatory clauses 
and generates grounded answers through four retrieval modes: 
lexical, semantic, hybrid, and RAG.

---

## Stack

FastAPI · Docker · AWS EKS · GitHub Actions · MLflow · 
Apache Airflow · Prometheus · Grafana · Gemini · Sentence Transformers
